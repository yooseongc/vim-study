YOUR FIELD NOTES00 / 06완료한 실전 미션

빠른 타이핑보다, 정확한 한 번의 편집.

콘솔에서 자유로워지는 학습 경로

① 생존: 모드·저장·되돌리기 → ② 의도 단위 편집: 검색·motion·text object → ③ 반복 제거: 점·치환·매크로 → ④ 작업 공간: 버퍼·분할·레지스터 → ⑤ 현장 전이: quickfix·argdo·필터·셸 왕복

아래 여섯 미션은 ①–④의 첫 훈련입니다. 미션마다 도움 없이 해결 → 힌트 확인 → 다른 방식으로 재도전 → 내 로컬 Vim에서 재현하는 순서를 권합니다. ⑤의 실전 과정과 간격 반복·변형 미션은 후속 구현 범위입니다.

실제 Vim 8.2 / 플러그인 없음 / 브라우저 가상 파일. :!grep 같은 외부 프로세스와 실제 서버 접속은 지원하지 않습니다. 키보드가 있는 데스크톱 사용을 권장합니다.
